Version 2 of the one-line laugh entry. The program writes a single original
funny line about everyday life to `/output/entry.txt` (1–200 characters).

## The line

> My smartwatch just congratulated me for standing up, which is the saddest trophy I've ever earned while sitting back down.

## Run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`.
